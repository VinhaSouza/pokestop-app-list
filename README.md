<h3> O aplicativo simula uma loja virtual, onde treinadores podem visualizar e comprar itens utilizados durante suas aventuras, como Poké Bolas, poções, repelentes e diversos acessórios. </h3>

> ⚠️ Este projeto foi desenvolvido apenas para fins de estudo e portfólio, sem qualquer vínculo oficial com a Nintendo, Game Freak ou The Pokemon Company.

3. Instale as dependências
    > npm install
4. Execute
    > npx expo start
